# Personal Portfolio Website

A modern, responsive personal portfolio website showcasing skills, projects, and resume.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Smooth Scrolling**: Navigation with smooth scroll animations
- **Hover Animations**: Interactive elements with hover effects
- **Semantic HTML5**: Proper use of HTML5 semantic elements for accessibility
- **CSS3 Animations**: Modern CSS animations and transitions
- **JavaScript Interactivity**: Smooth scrolling, form handling, and scroll animations

## Sections

- **About**: Personal introduction and profile picture
- **Projects**: Showcase of key projects with descriptions
- **Resume**: Professional experience, education, and skills
- **Contact**: Contact information and contact form

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- JavaScript (ES6+)

## Local Development

1. Clone or download the repository
2. Open `index.html` in your web browser
3. The website will load with all styles and scripts

## Deployment

### Option 1: GitHub Pages

1. Create a new repository on GitHub
2. Upload all files from this project to the repository
3. Go to Settings > Pages
4. Under Source, select "Deploy from a branch"
5. Select "main" branch and "/ (root)" folder
6. Click Save
7. Your site will be published at `https://yourusername.github.io/repository-name`

### Option 2: Netlify

1. Sign up for a free account at [Netlify](https://netlify.com)
2. Click "New site from Git" or "Deploy manually"
3. If deploying manually:
   - Drag and drop the project folder into the deployment area
4. If connecting to Git:
   - Connect your GitHub repository
   - Set build command to `echo "No build step"`
   - Set publish directory to `/`
5. Click "Deploy site"
6. Your site will be live with a Netlify subdomain

## Customization

- **Personal Information**: Edit the content in `index.html` to add your personal details
- **Styling**: Modify `styles.css` to change colors, fonts, and layout
- **Functionality**: Update `script.js` to add more interactive features
- **Images**: Replace placeholder images with your actual profile picture and project screenshots
